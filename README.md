# 地球探索 🌍

> 用故事探索世界、语言与文化。

**地球探索** 是一个以地点和人物故事为入口的互动文化产品。  
用户不是来考试，而是通过城市、日常生活、语言和文化细节进入一个地方。

- 下一篇：BJ-002《前门来了一个外乡人》

## 产品原则

- 不做考试式体验
- 不做积分、排名、强制闯关
- AI 可以帮助创作故事，但不能创造历史事实
- 真实地点与历史信息遵循 Fact Lock
- 先用故事让人进入地方，再让语言自然发生
